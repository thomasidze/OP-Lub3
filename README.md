#Лабораторная работа №3

##Тема
Одномерные массивы и методы

##Цель работы
Научиться работать с одномерными массивами, использовать методы для выполнения
различных задач, включая сортировку массивов и сравнение времени выполнения
различных алгоритмов сортировки.

##Дополнения
Блок-схема кода приложена к проекту в файлах:
- "Лаба3_блок-схема.graphml" для открытия в yEd;
- "Лаба3_блок-схема_превью.svg" для открытия в браузере.

##Как установить и запустить
Выполните команду `git clone https://github.com/thomasidze/OP-Lub3`;
Установите .NET SDK;
Выполните команду `dotnet run`.
